O_RDONLY

const O_RDONLY: 0 = 0

Defined in: packages/pgwasm/src/opfs/broker/protocol.ts:163

POSIX/WASI-shaped open bits. The wire carries these, never the core’s node-style flag string: a WASI path_open maps its oflags/fdflags/fs_rights_base onto them directly, and the server is the only place that has to know the core’s string vocabulary.
